# Custom Tech Icons Folder

Place your custom PNG, JPG, WEBP, or SVG icon files directly into this directory (`src/assets/tech/`).

### Naming Guide:
Name your PNG files after the technology name (lowercase):

- `html.png`
- `css.png`
- `javascript.png` (or `js.png`)
- `typescript.png` (or `ts.png`)
- `react.png`
- `bootstrap.png`
- `nodejs.png` (or `node.png`)
- `expo.png`
- `vite.png`
- `php.png`
- `laravel.png`
- `mysql.png`
- `postgresql.png`
- `supabase.png`
- `vercel.png`
- `git.png`
- `github.png`
- `docker.png`
- `figma.png`
- `framer.png`

Any file added here will automatically override the default SVG vector icons in the Tech Arsenal and Marquee!
